# CreateIndex

> 使用此API可创建两类知识库：基于文档或音视频的非结构化知识库，以及用于数据查询或图片问答的结构化知识库。

<meta property="og:title" content="CreateIndex" />

## 接口说明 <span id="api-detail-51" />

- 权限要求：

  - <strong>RAM 用户（子账号）</strong>：需先获取阿里云百炼的 [API 权限](/zh/model-studio/grant-data-access-permission-to-ram-user)（可使用`AliyunBailianDataFullAccess`策略，该策略已包含本接口所需的 sfm:CreateIndex 权限点），并[加入一个业务空间](/zh/model-studio/grant-the-business-space-permission-to-ram-users)后，才能调用本接口。
  - <strong>阿里云账号（主账号）</strong>：默认拥有权限，可直接调用。
- <strong>调用方式</strong>：推荐使用最新版[阿里云百炼 SDK](https://api.aliyun.com/api-tools/sdk/bailian?version=2023-12-29)调用，SDK 已封装复杂的签名计算逻辑，可简化您的调用过程。
- <strong>后续操作</strong>：本接口仅初始化知识库创建作业。完成调用后，必须调用 <strong>SubmitIndexJob</strong> 接口以完成创建（否则，您将得到一个空的知识库）。相应代码示例请参见[知识库 API 指南](/zh/model-studio/rag-knowledge-base-api-guide)。
- <strong>幂等性</strong>：本接口不具有幂等性，重复调用可能会创建多个同名知识库。建议通过“先查询、后创建”的逻辑实现幂等调用。

<strong>限流说明：</strong>
本接口频繁调用会被限流，频率请勿超过 10 次/秒。如遇限流，请稍后重试。
