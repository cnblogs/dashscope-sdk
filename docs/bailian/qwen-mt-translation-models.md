# 翻译模型

> 阿里云百炼翻译模型总览，涵盖文本翻译、图片翻译与全模态翻译。

<meta property="og:title" content="翻译模型" />

阿里云百炼提供以下翻译模型 API：

- [Qwen-MT API 参考](/zh/model-studio/qwen-mt-api)：文本翻译，支持 OpenAI 兼容接口与 DashScope API。
- [Qwen-MT-Image API 参考](/zh/model-studio/qwen-mt-image-api)：图片翻译，精准还原图文排版。
- [Qwen-MT-Uni API 参考](/zh/model-studio/qwen-mt-uni-api)：全模态翻译，支持文本、文档、图片、音频输入。
