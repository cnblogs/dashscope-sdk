# Retrieve

> 在指定的知识库中检索信息。

<meta property="og:title" content="Retrieve" />

## 接口说明 <span id="api-detail-51" />

- <strong>调用方式</strong>：本页描述 OpenAPI Retrieve 接口 `POST /{WorkspaceId}/index/retrieve`，可通过最新版[阿里云百炼 SDK](https://api.aliyun.com/api-tools/sdk/bailian?version=2023-12-29)并使用阿里云访问密钥 [AccessKey](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair)调用。[Spring AI Alibaba](/zh/model-studio/spring-ai-alibaba-integrate-knowledge-base)使用阿里云百炼 [API Key](/zh/model-studio/get-api-key)和独立的 DashScope Pipeline Retrieve 路径，不使用本页的 OpenAPI 请求语法。
- 权限要求：

  - <strong>RAM 用户（子账号）</strong>：需先获取阿里云百炼的 [API 权限](/zh/model-studio/grant-data-access-permission-to-ram-user)（可使用`AliyunBailianDataFullAccess`策略，该策略已包含本接口所需的 sfm:Retrieve 权限点），并[加入一个业务空间](/zh/model-studio/grant-the-business-space-permission-to-ram-users)后，才能调用本接口。
  - <strong>阿里云账号（主账号）</strong>：默认拥有权限，可直接调用。
- <strong>响应延迟</strong>：由于接口调用包含复杂的检索和匹配，响应时间可能较长，建议您合理设置请求的超时与重试策略。
- <strong>幂等性</strong>：本接口具有幂等性。
